# 3D 数字形象 / 3D mascot

`mascot-final.png` is a modified derivative of the **Man raising hand** 3D emoji from
[Microsoft Fluent Emoji](https://github.com/microsoft/fluentui-emoji), sourced from the
`Medium-Light` skin-tone variant.
